# Movie App

This is a movie app built with React and Vite. It uses the TMDB API to fetch movie data and display it in a user-friendly interface.

## Features

- Search for movies by title or IMDB ID
- View trending movies
- View all movies
- Filter movies by genre
- Filter movies by release year
- Filter movies by rating

## Getting Started

To get started, you'll need to create an account on the TMDB API. Once you have an API key, you can set it as an environment variable in your project.

1. Create a new React project using Vite:

```bash
npm create vite@latest movie-app
```

2. Install the necessary dependencies:

```bash
npm install react react-dom react-use
```

3. Set your TMDB API key as an environment variable:

```bash
export VITE_TMDB_API_KEY=your_api_key
```

4. Start the development server:

```bash
npm run dev
```

5. Open your browser and navigate to `http://localhost:3000` to see the app in action.
